# Печать Дома 🖨️

Домашняя очередь на 3D-принтер: вход по коду, каталог моделей (MakerWorld / Bambu Lab), очередь с именами, база Neon и уведомления в Telegram прямо с Vercel.

## Запуск на Vercel

1. Залей репозиторий на GitHub → **Vercel → Add New → Project → Import**.
   Framework Preset: **Other**, Build Command пустой.
2. **Storage → Create → Neon (Postgres)** и подключи к проекту. Появится `DATABASE_URL`.
   Таблицы создадутся сами при первом заходе.
3. **Settings → Environment Variables**:

| Ключ | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота (такой же, как в проекте `qauipsiz-telegram-bot-vercel`) |
| `TELEGRAM_OWNER_ID` | твой Telegram ID (такой же, как в `opportunity-radar-bot`) |
| `ADMIN_PASSWORD` | пароль режима мастера (🛠️), придумай свой |
| `SITE_PASSWORD` | *(необязательно)* код входа, по умолчанию `676912` |
| `AUTH_SECRET` | *(необязательно)* любая длинная строка для подписи сессий |

4. **Redeploy**.

## Что умеет

- 🔒 Вход по 6-значному коду (защита от подбора: 12 неверных попыток → пауза 15 минут).
- 🧩 Каталог из 30+ моделей по категориям с поиском и ссылками на MakerWorld, плюс «Своя модель» по ссылке.
- 📋 Очередь: имя, цвет пластика, количество, комментарий, место в очереди и примерное время ожидания.
- 🔥 Блок «Сейчас печатается» с прогрессом.
- 📨 Telegram: сообщение о каждой новой заявке и о готовой модели.
- 🛠️ Режим мастера: запустить, готово, поднять наверх, отменить, вернуть, удалить, добавить модель в каталог.
- Не больше 3 активных заявок на одно имя, чтобы дети не заспамили очередь.

## Структура

```
index.html          страница
assets/styles.css   дизайн
assets/app.js       логика фронта
assets/catalog.js   встроенный каталог (можно дополнять)
api/login.js        вход
api/queue.js        очередь + Telegram
api/catalog.js      свои модели в каталоге
api/_lib.js         БД, токены, Telegram
```
